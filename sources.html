史料来源与教学说明

本体验的边界：页面中的道路、山体、天气和第一人称视角由程序绘制，属于艺术化教学模拟，不是真实历史影像、实景扫描或士兵日记。路线为概念性导航，不是精确测绘地图。

建议优先核对的资料

  1. 中共中央党史和文献研究院公开发布的党史资料、党史著作及相关历史文献。
  2. 中国共产党历史展览馆及长征沿线纪念馆、博物馆的正式展陈和出版物。
  3. 权威出版机构出版的长征史、红军战史与历史文献。
  4. 亲历者回忆录、口述资料。使用时注意作者身份、写作时间、叙述视角，并与其他资料交叉核对。

使用历史资料时注意

  • 中央红军、红一方面军及其他方面军的组织称谓随历史阶段变化，使用时注意语境。
  • 不同部队的出发、行军、到达和会师时间并不完全相同。
  • 伤亡人数与战斗细节可能因资料来源、统计口径不同而有差异。正式作业应记录书名、作者/编者、出版社、年份、页码或网页标题与访问日期。
  • 文学作品、影视作品和纪念性叙事有助于理解历史记忆，但不能自动作为具体战斗细节的直接证据。

版本说明

14.0采用 Canvas 绘制的第一视角道路、地形层次、移动视差、环境粒子与虚拟摇杆。移动端可触屏移动，桌面端可用 WASD 或方向键。该版本没有外部资源依赖，适合直接部署到 GitHub Pages。

此版本的沉浸感来自程序生成的场景，而不是实际三维游戏引擎或真实纪录片素材。后续如加入历史照片、纪录片视频，应单独核验版权、来源与史实语境。
