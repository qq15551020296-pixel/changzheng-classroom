# 重走长征路 12.0｜沉浸式长征体验

## 文件说明
- `index.html`：完整交互网站（HTML/CSS/JavaScript 内嵌，无需构建工具）
- `sources.html`：历史来源与真实性说明
- `.nojekyll`：用于 GitHub Pages
- `README.md`：部署与使用说明

## 本地打开
下载并解压 ZIP，点击 `index.html` 即可在现代浏览器打开。部分浏览器可能限制本地存储；推荐通过 GitHub Pages 访问，以便保存探索进度。

## GitHub Pages 部署
1. 先下载并保存旧版 9.0 备份，不要删除备份。
2. 打开现有仓库 `qq15551020296-pixel/changzheng-classroom`。
3. 进入仓库根目录，选择 **Add file → Upload files**。
4. 上传并覆盖 `index.html`、`sources.html`、`README.md`、`.nojekyll`。
5. 提交到 `main` 分支，提交说明可写 `Deploy immersive Long March 12.0`。
6. 等待 GitHub Pages 更新，打开原网站地址。若仍看到旧页面，可刷新或清除浏览器缓存。
7. 测试首页进入、地图选点、场景前进、资料弹窗、来源链接和刷新后进度保存。

## 功能说明
- 第一人称教学模拟式场景叙事
- 13 个长征重要节点，可通过路线地图选择与回访
- 通过“历史背景”“现场观察”“相关史料”自然探索知识
- 沿途史料档案与来源页面
- 自动保存已探索地点（浏览器 localStorage）
- 响应式移动端布局
- 无教师模式、无考试式闯关

## 真实性与使用边界
- 场景光影、路线图、互动道具和第一人称叙事属于教学模拟。
- 重要历史内容提供权威来源链接；本网站摘要不替代来源原文。
- 地图是学习示意，不是精确地理或军事地图。
- 本版本不包含未经授权的历史影像、音乐或真实录音；氛围由 CSS 视觉效果营造。
- 发布前建议逐条核对来源页面，并按课程要求补充规范参考文献。
