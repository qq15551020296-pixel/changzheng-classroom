# 《重走长征路 13.0》GitHub Pages 部署包

## 本版本改动
- 以电影纪录片式的全屏开场、地貌层次、雾气/雨雪动画取代传统 PPT 卡片观感。
- 路线改为带有地形等高线、河谷、发光行军轨迹和可点击节点的叙事化示意图。
- 每个节点进入独立的场景叙事：环境氛围、第一人称感受、历史概述与“史实/模拟”说明分开呈现。
- 增加行军片段、史料档案弹层、行军笔记、本地进度保存。
- 手机端响应式适配；无外部依赖，GitHub Pages 可直接托管。
- 保留学生自主体验，不包含教师授课模式。

## 上传到 GitHub Pages
1. 先备份仓库当前版本（建议在 GitHub 仓库创建一个旧版分支，或下载仓库 ZIP）。
2. 解压部署包。
3. 将 `index.html`、`sources.html`、`README.md`、`.nojekyll` 上传到仓库根目录，覆盖同名文件。
4. 点击 Commit changes（提交更改）。
5. 等待 GitHub Pages 发布后，刷新网页；iPhone Safari 可尝试重新载入或无痕浏览检查缓存。

## 注意
- 路线地图是概念性教学示意图，不是精确比例尺地图。
- CSS/SVG 地貌动画是艺术化情境，不是真实历史照片或现场复原。
- 正式课程作业请按“史料来源与教学说明”继续补充具体书目、页码与网页引用。
- 页面使用浏览器 localStorage 保存当前设备的进度和笔记；清理浏览器数据后可能丢失。
