# 重走长征路 18.0｜全关卡3D沉浸式学生自主体验版

## 文件
- `index.html`：三维互动课堂主程序
- `sources.html`：史料核验与模拟场景说明
- `.nojekyll`：GitHub Pages 配置辅助文件

- 增加关卡学习任务、按关卡配置的判断题、即时反馈与本地进度保存。

## GitHub Pages 替换步骤（手机也可操作）
1. 解压 ZIP。
2. 打开你现有的 GitHub 仓库。
3. 进入仓库根目录，选择 `Add file` → `Upload files`。
4. 上传本包里的 `index.html`、`sources.html`、`.nojekyll`，选择覆盖同名文件。
5. 在页面底部填写提交说明，例如 `Upgrade to 18.0`，点击 `Commit changes`。
6. 打开现有 GitHub Pages 网站，刷新页面。若仍显示旧版，关闭页面后重新打开，或在网址末尾临时添加 `?v=18` 再访问。
7. 若网站首次打开时是黑屏，请确认设备网络可访问 jsDelivr，因为 Three.js 从 CDN 加载；这版没有把 Three.js 库打包进 ZIP。

## 控制方式
- 鼠标/手指拖动：观察场景。
- 点击金色标记：打开本关档案。
- 点击“开启行走”后，桌面使用 WASD/方向键，手机使用左下角摇杆。
- 点击“本关任务”完成知识判断；进度和手记保存在当前浏览器。
- 点击“行军手记”查看学习记录。

## 重要说明
这是课程设计原型，当前版本未在真实 iPhone 与你的 GitHub Pages 仓库上完成端到端测试。地形、桥梁、建筑、天气和道具由程序生成，属于艺术化教学模拟；不应作为历史现场影像或精确测绘数据。史实文字提供学习摘要与核验方向，正式提交作业前请按 `sources.html` 的格式补全准确书目、页码和网址。
