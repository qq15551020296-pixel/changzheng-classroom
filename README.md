# 《重走长征路 14.0》第一视角行军体验

## 本版主要升级
- Canvas 实时绘制的第一视角山路、远近山体、道路透视、视差与环境粒子。
- 电脑端支持 WASD / 方向键移动；手机端支持虚拟摇杆，建议横屏。
- 靠近行军标记后触发历史现场弹层，阅读事件背景、可核对史实和教学模拟说明。
- 提供史料说明、行军笔记、本地进度保存与轻微可选氛围音。
- 纯本地 HTML/CSS/JavaScript，无第三方依赖，适配 GitHub Pages。

## 部署
1. 备份当前仓库版本。
2. 解压 ZIP。
3. 将 `index.html`、`sources.html`、`README.md`、`.nojekyll` 上传至仓库根目录并覆盖同名文件。
4. 点击 Commit changes 提交。
5. 等待 GitHub Pages 发布后刷新页面；手机端建议横屏体验。

## 操作
- 电脑：WASD / 方向键移动，点击“环顾”改变视角。
- 手机：左下虚拟摇杆移动。
- 靠近标记后，点击右下角“交互”进入历史现场。
- “史料”查看史实边界，“行军笔记”保存个人反思。
- 本地进度与笔记使用浏览器 localStorage 保存，清理浏览器数据后可能丢失。

## 历史与技术边界
场景由 Canvas 程序生成，属于艺术化教学模拟，不是真实历史照片、实景扫描、三维引擎或真实士兵日记。路线是概念性导航，不是精确比例尺地图。正式课程作业请进一步补充具体可靠史料的书名、页码或网页引用。
